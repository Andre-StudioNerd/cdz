## 🧑‍🚀 Cavaleiros do Zodíaco  

Uma página temática inspirada no anime Cavaleiros do Zodíaco, com informações sobre personagens, sagas e muito mais!  

## 🌐 Demonstração  
Acesse a página ao vivo em: [Cavaleiros do Zodíaco](https://andre-studionerd.github.io/cdz/)  

## 🚀 Tecnologias  
- HTML5  
- CSS3  
- JavaScript  

## ✨ Funcionalidades  
- Informações detalhadas sobre os Cavaleiros do Zodíaco  
- Design responsivo e temático, inspirado na estética do anime  
- Navegação intuitiva entre as seções de personagens e sagas  
- Animações e efeitos visuais para uma experiência imersiva  

## 📥 Como rodar o projeto localmente  
1. Clone o repositório:  
    ```bash
    git clone https://github.com/Andre-StudioNerd/cdz.git
    ```
2. Acesse o diretório do projeto:  
    ```bash
    cd cdz
    ```
3. Abra o arquivo `index.html` no navegador.
